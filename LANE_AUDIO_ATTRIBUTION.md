# Audio asset credits

This directory contains renamed and converted guitar audio samples sourced from Freesound.

The files in this folder were modified from their original source assets for use in this project. Modifications may include:
- renaming
- trimming
- format conversion
- normalization
- mapping to gameplay lanes / sustain slots

## Modification note
All files in this folder are redistributed as project-ready assets and do not retain their original Freesound filenames. They were renamed into the following in-project scheme:

- `hit*.ogg` / `sustain*.ogg` for the heavy set
- `funk-hit*.ogg` / `funk-sustain*.ogg` for the light clean set

## Summary
- `hit*` and `sustain*` = modified heavy guitar assets derived from **Ax_Grinder** sources, licensed under **CC BY 3.0**
- `funk-hit*` and `funk-sustain*` = modified light clean guitar assets derived from **guitarmaster** and **Skirox** sources, both licensed under **CC0 1.0**
